* 🐍 FastAPI backend with AI integration.
* 🤖 Local LLM experimentation using Ollama.

* 🗄️ PostgreSQL database and REST API architecture.

**Tech:** React · FastAPI · Python · PostgreSQL · Machine Learning · Docker
